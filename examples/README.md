# Examples

`sample-folder/` is the folder the quick start sorts: 19 top-level files and one existing project folder (`rhythm-game/`). It is one of the dev folders used while building the tool, so it is not part of the unseen folders the report judges on.

Copy it before trying it, so the original stays as it is:

```sh
cp -R examples/sample-folder workspace
```

The quick start's list sorts it into `gpu-bench`, `tax-2026` and `wedding`, plus the existing `rhythm-game`. Three files (`IMG_2231.jpg`, `untitled.txt`, `notes.md`) belong to no project and should stay where they are.
